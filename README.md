### Rn:CS (for CS:MOS)
源地址：https://github.com/nillerusr/srceng-android

### 闭源通知
由于外挂数量的持续增加，我们决定调整 Rn:CS 的开发方向。为进一步提升游戏安全性和玩家体验，启动器将进行反作弊模块的全面升级。因此，项目后续将不再以开源形式进行维护与发布，敬请理解与支持

#### 说明
(初始目标)
1. 反编译了最新版apk，将java源码适配最新版。添加最新v6.5&v7.5游戏动态库。
2. 适配了Gradle编译(原来的源码不知道咋编译，而且去年停止开源)
3. (正在进行)重做一个更好用的启动器

(截止至2025.6.27已完成特性)
1. 支持远程动态添加游戏动态库和版本（也支持内置游戏版本动态库和vpk）
2. 支持游戏数据包下载
3. 支持多游戏版本管理，设置独立路径和启动参数
4. 支持免启动游戏查看服务器列表，可通过列表直接进入服务器
5. 支持高亮编辑启动命令`autoexec.cfg`
6. 支持选择版本启动
7. 截止目前已支持CS:MOS,ClientMod,CS:SO三种Mod版CS起源
8. 完成小部分论坛和资源模块
9. 支持自定义房间，通过论坛获取CDK，拥有一个可自定义参数的服务器房间
10. 修复了原版启动器的一些bug，如二次启动崩溃等问题
11. 通过注入游戏，修复了一些游戏问题和新增一些特性（如CS:MOS v6.5支持游戏内弹窗输入密码）
